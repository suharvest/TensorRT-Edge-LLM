Qwen3-TTS minimal repro artifacts
=================================

This branch only stores small validation artifacts referenced from a GitHub
issue. It is not the code branch for the repro.

Files:

- `qwen3-tts-minimal-stateful-slim.wav`: Chinese sample generated by the
  minimal stateful repro.
- `qwen3-tts-minimal-stateful-slim-output.json`: runtime metadata for the
  Chinese sample.
- `qwen3-tts-minimal-stateful-en.wav`: English sample generated by the same
  path.
- `qwen3-tts-minimal-stateful-en-output.json`: runtime metadata for the English
  sample.
